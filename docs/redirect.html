How It Works

1
Install the extension from the Chrome Web Store.
2
Click an HTTP(S) bookmark in your bookmark bar or menu.
3
The destination opens in a new tab, or reuses the exact blank source tab when configured. A non-empty source page remains loaded.
Note: The extension modifies your bookmark URLs with a reversible query marker to enable the new-tab behavior. Pause it from the popup before disabling or uninstalling so current-format bookmarks are restored first.
