Privacy Policy

Open Bookmarks in New Tab — Chrome Extension
Last updated: August 19, 2026

1. Overview

"Open Bookmarks in New Tab" is a Chrome extension that automatically opens bookmarks in a new tab instead of replacing your current tab. This privacy policy explains what data the extension handles (and does not handle) and why each permission is required.

2. Data Collection

The developer does not collect or receive personal data through this extension. It uses no analytics, tracking, advertising, remote code, or runtime third-party service.

The extension processes bookmark URLs locally so it can add and remove a reversible marker. Behavior and language preferences may be synchronized between the user's signed-in Chrome profiles through chrome.storage.sync, along with a randomly generated 128-bit marker-owner key used to recognize the extension's own bookmark markers. Transition state and, during a version 2.3 migration, a size-limited backup containing as many affected bookmark URLs as fit stay in chrome.storage.local. The backup is removed on the first extension startup at least 30 days after it was created. None of this data is sent to the developer.

3. Permissions and Justifications

The extension requests the following permissions. Each one is essential to the extension's core, single purpose. No permission is used for data collection or tracking.

Permission Why It Is Needed
bookmarks Reads and modifies HTTP(S) bookmark URLs to add or remove the __obnt_v4 marker. It contains a random installation-scoped owner, a migration-provenance flag, and a random 256-bit per-bookmark nonce. The extension also migrates the released newtab@ format. Pausing from the popup restores current-format URLs.
tabs Creates and positions one destination tab, or reuses the exact empty source tab. The current source-tab URL and placement metadata are valid for recovery for up to 15 seconds and remain only in transient service-worker memory so concurrent folder tabs can be handled without changing an unrelated active tab.
webNavigation Detects marked top-level navigations before commit. The event URL is handled transiently and is not retained as browsing history by the extension.
declarativeNetRequest Redirects only a top-level URL ending in this extension's exact marker to the bundled cancel.html resource. The local service worker returns HTTP 204, cancelling that marked source request without creating a dummy download. The clean destination is then requested normally in the destination tab while the extension is active in a supported regular window.
alarms Schedules a periodic no-op wake-up while the extension is enabled, so the service worker is already running when a bookmark is clicked. Without it the browser must start the worker before the marked request can be cancelled, which leaves the page you are reading waiting. The alarm carries no data and does nothing when it fires; pausing the extension clears it.
storage Synchronizes behavior and language preferences plus the random marker-owner key through Chrome, and stores migration/transition state plus the temporary legacy backup locally.
Host permissions HTTP(S)-only host access lets DNR and webNavigation match marked bookmarks on any web host. The extension does not read or alter page content.

4. Third-Party Services

This extension does not integrate any developer-operated third-party service, API, analytics platform, advertising network, or tracking tool. Chrome may synchronize preferences through the user's signed-in browser profile; that browser feature is operated by Google, not the developer.

5. Data Sharing

The developer does not receive bookmark URLs, settings, or migration backups. A marked source request is cancelled locally before reaching its destination while the extension is active. The clean destination URL is then requested normally from that website in a new or reused empty tab. The extension does not run in incognito windows, and Chrome cannot run cleanup during direct disable or uninstall. Pause from the popup before using bookmarks incognito, disabling, or uninstalling so no marker remains as an ordinary website query parameter.

6. Data Security

Preferences and the random marker-owner key use Chrome's synchronized extension storage. Transition state and time-limited migration backups use local extension storage. These records are accessible only to this extension under normal browser security. The extension minimizes retained state and does not transmit it to a developer-controlled service.

7. Remote Code

This extension does not use any remote code. All JavaScript is bundled locally within the extension package. There are no external <script> tags, no dynamically loaded modules, and no use of eval() or similar functions.

8. Children's Privacy

The developer does not collect personal data from anyone through this extension, including children under the age of 13.

9. Changes to This Policy

10. Compliance
